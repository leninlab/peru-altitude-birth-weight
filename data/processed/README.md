# Processed analytic datasets

These analysis-ready CSV files were derived from publicly available ENDES and CNV data for 2020–2024.

## ENDES

- `ENDES_2020_2024_birth_weight_card.csv`: primary sample using birth weights recorded on the child’s health card.
- `ENDES_2020_2024_birth_weight_card_recall.csv`: expanded sample including health-card-recorded and maternally recalled birth weights.

## CNV

- `cnv_province_year_2020_2024.csv`: ecological dataset with 954 province-year observations from 193 provinces. Each row contains the number of registered live births with low birth weight, the total number of registered live births, and provincial-capital altitude as an exposure proxy.

## Data licenses and attribution

The ENDES-derived datasets are based on data from the Instituto Nacional de Estadística e Informática (INEI) and are made available under the Open Data Commons Open Database License (ODbL).

The aggregated CNV dataset is based on data from the Ministerio de Salud del Perú (MINSA) and is made available under the Open Data Commons Attribution License (ODC-BY).

The processed datasets were prepared by the study authors. Please cite the original data sources and this repository when using them.
