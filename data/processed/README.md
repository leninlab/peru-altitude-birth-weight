# Processed ENDES data

These analysis-ready CSV files were derived from the publicly available ENDES microdata for 2020–2024.

- `ENDES_2020_2024_birth_weight_card.csv`: primary sample using birth weights recorded on the health card.
- `ENDES_2020_2024_birth_weight_card_recall.csv`: expanded sample including health-card and maternal-recall birth weights.
