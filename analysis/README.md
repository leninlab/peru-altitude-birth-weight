# Analysis scripts

This directory contains the analysis code for the ENDES and CNV components of the study.

- `01_endes_primary_analysis.R`: R script for the primary individual-level ENDES analysis.
- `02_cnv_analysis.py`: Python script for the descriptive and regression analyses of CNV data.
- `02_cnv_analysis.ipynb`: Jupyter notebook version of the CNV analysis.

The ENDES script uses the processed datasets in `data/processed/`. The CNV script and notebook use `data/processed/cnv_province_year_2020_2024.csv`.
